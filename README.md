# Каитхэ Лаоши — сайт и демо онлайн-школы

Сайт разработан Дарией Кромберг.

## Страницы
- `index.html` — сайт: уроки, цены, мини-уроки, карточки, методички, запись
- `school.html` — демо-кабинет (вход как ученик или преподаватель)
- `room.html` — комната урока: видео Jitsi, доска для иероглифов, слайды

## Где что менять
- `data.js` — контакты (CONFIG), слова для карточек (WORDS), мини-уроки (MINI), методички (FILES), демо-ученики (DEMO)
- цены и тексты — в `index.html`
- PDF-методички лежат рядом: `shpargalka-tony.pdf`, `propisi.pdf`, `hsk1-slova.pdf`

## Загрузка на GitHub Pages
Загрузите все файлы в корень репозитория (без папок), включите Pages: Settings → Pages → main / root.

## Ограничения демо
- Данные кабинета (оценки, домашка) сохраняются только в браузере, где их поменяли.
- Доска не синхронизируется между учеником и учителем — для этого нужна база (например, Supabase Realtime).
- Встроенное видео meet.jit.si бесплатно, но во встроенном виде звонок обрывается через 5 минут; для полного урока есть ссылка «в новой вкладке» или бесплатный тариф JaaS (8x8).
